welcome to Tiny Desktop

about this page:

this is an attempt to make a usable mini desktop in browser

this desktop is made only from files below 1000 bytes compressed.
* for better - 1500 bytes is a typical size of a network packet so pages may fit in one packet as https uses compression - although this desktop is not about network usage but simply about being small

here you can use some tools, office like apps or simply play games
